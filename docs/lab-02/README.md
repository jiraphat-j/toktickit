# Lab 2 Engineering Contract

This folder is the version-controlled engineering contract for Lab 2. Create and approve these documents before
implementation begins:

| File | Purpose | Status |
|---|---|---|
| `specification.md` | Scope, functional requirements, business rules, data decisions, acceptance criteria, and Definition of Done | Ready for review |
| `api-spec.md` | Endpoint request/response contracts, status codes, pagination, validation, and safe errors | Ready for review |
| `ui-spec.md` | Zen Green component rules, screen states, accessibility, and responsive behavior | Ready for review |
| `tests.md` | Planned-test table, AC-to-test traceability, commands, and final results | Ready for review |
| `reviewer.md` | Reviewer identity, PRs, comments, replies, and approvals | In progress during PR review |
| `ai-use.md` | Selected AI prompts, review decisions, and reflection | In progress throughout the sprint |

The final repository is the source of truth. Do not begin feature implementation until the first four documents
are reviewed together and their requirements are internally consistent.
